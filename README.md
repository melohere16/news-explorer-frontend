# 📰 NewsExplorer

NewsExplorer is a responsive React application that allows users to search for recent news articles and save their favorites.

## ✨ Features

- 🔎 Search for the latest news by keyword
- 🔖 Save and delete articles
- 👤 Sign up and sign in
- ➕ Load more results with "Show more"
- ⚠️ Loading, error, and "Nothing found" states
- 📱 Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies

- React
- JavaScript
- Vite
- CSS
- React Router
- News API
- Local Storage

## 🚀 Run Locally

```bash
npm install
npm run dev
```
